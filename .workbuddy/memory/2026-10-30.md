# 2026-10-30

## 修复 GitHub issue #1（Serein1202/License-guard）

针对 https://github.com/Serein1202/License-guard/issues/1 里用户与 AI 报出的问题，做了四处修复：

1. **设备指纹 v2**（`clients/{dotnet,python,node}`）
   - 移除参与哈希的可变因子：主机名、OS 版本、CPU 架构。它们导致用户改电脑名/升级系统后指纹漂移，白占设备位（单机授权直接 DEVICE_LIMIT）。
   - Windows 新增：BIOS prod/board、CPU Identifier/ProcessorNameString、系统盘卷序列号（C# 用 P/Invoke `GetVolumeInformationW`，零 NuGet 依赖）。
   - MAC 从"无条件兜底"改为"仅在硬件因子全取不到时使用"，避免换网卡漂移。
   - 保留 v1 算法（C# `ComputeLegacy()` / Python `legacy_machine_id()` / Node `legacyMachineId()`），随请求上报 `machine_id_alt`。

2. **激活迁移**（`worker/src/db.ts::resolveMachineId`）
   - 命中旧指纹记录时 `UPDATE OR IGNORE` 把 machine_id 改成新值，老用户不掉激活。

3. **设备数并发竞争**（`db.ts::upsertActivation`）
   - 原来 countActivations + INSERT 两步非原子。改成单条 `INSERT ... SELECT ... WHERE EXISTS(...) OR COUNT(*)<max ON CONFLICT DO UPDATE`，并在 evaluate 与写入之间被抢位时补判 DEVICE_LIMIT。

4. **看门狗间隔语义**（三端）
   - `watchdog_interval_sec > 0` 现在是固定间隔，不再被后端 heartbeat_sec 覆盖。
   - 历史缺陷：Python 首次成功后改用 heartbeat_sec（默认 6 小时）、Node/C# 改用 min(hb, 900)，配 15 秒实际 15 分钟才复查。

新增 `worker/tests/test_activation_atomic.py`（本地 SQLite 复刻 D1 表验证原子性与迁移，14 个用例全过），
`package.json` 加 `npm run test:activation`。

文档同步：README、docs/SECURITY.md、docs/INTEGRATION.md、skill/references/{api,integration}.md，
以及 skill/assets/clients 下三端 SDK 副本（原本与 clients/ 完全一致，改完已 cp 同步）。
